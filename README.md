# nutrition-tracker

> 一个为「增肌减脂」而生的极简营养工具 —— 也是我的第一个 GitHub 项目。

## 为什么做这个

本人软件工程专业在读，正在执行增肌减脂计划（87kg → 80kg）。
平时在资料库里积累了大量食材热量 / 宏量营养素数据，
干脆把它们整理成结构化数据 + 一个小脚本，既能练手，也能真正用在日常饮食记录上。

## 项目内容

| 文件 | 说明 |
| --- | --- |
| `nutrition-data.csv` | 常见食材每 100g 的热量、蛋白质、脂肪、碳水、钠（部分来自资料库营养表导出） |
| `macro_calculator.py` | Python 脚本：输入「食物名 + 重量」，计算一顿饭的宏量营养素合计 |

## 快速开始

```bash
# 需要 Python 3
python macro_calculator.py
```

按提示输入 `食物名 重量(g)`，例如：

```
> 鸡胸肉（生，去皮） 180
> 荞麦面条（生，干面） 100
> 番茄 150
>
```

即可看到这顿饭的热量与三大营养素合计。
